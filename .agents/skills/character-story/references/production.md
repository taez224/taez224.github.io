# 제작과 검토

## 입력 구성

이번 콘티에 필요한 기준 이미지를 사용한다. 캐릭터가 없으면 인물 시트를 필수로 넣지 않고 채택된 장면의 선·채색·재질감 등을 참고한다. 시각적 톤 참고와 등장시킬 대상을 구분해 도구에 전달한다. 이미지마다 인물 정체성, 필요한 각도, 소품 상태, 배경·구도 중 무엇의 기준인지 적는다. 여러 포즈가 있는 시트를 첨부했다면 시트 배열이나 모든 포즈를 복제하지 않도록 명시한다. 탈락안과 외부 캐릭터 이미지는 현재 인물 기준에 섞지 않는다.

공통으로 유지할 외형·채색과 컷마다 바뀌는 행동·표정·구도를 분리한다. 이전 생성물만 계속 다음 컷의 인물 기준으로 쓰면 작은 변형이 누적될 수 있다. 인물이 재등장하는 다음 컷에도 인물 정본 이미지를 유지하고, 채택한 장면은 장소와 구도 참고로 추가한다. 텍스트 프롬프트나 seed만으로 동일성을 보장한다고 말하지 않는다.

같은 구도의 반복·페이드·부분 교체는 채택한 장면 하나에서 카메라 위치, 인물 크기, 주요 소품 위치를 고정하고 필요한 부분만 편집한다. 이 위치가 흔들리면 의도한 변화보다 불일치가 먼저 보인다. 시간대가 바뀌면 창밖뿐 아니라 그림자와 실내 조명도 함께 맞춘다. 다른 구도로 전환하는 장면에는 이 고정을 강제하지 않는다.

## 생성 단위와 수정

짧고 단순한 만화는 한 장에 만들 수 있고, 컷별 수정이나 개별 슬라이드가 필요하면 파일을 나눌 수 있다. 콘티에서 정한 표시 방식과 수정 비용으로 선택한다. 여러 컷을 합쳐 생성한 후 컷 경계를 임의로 잘라 맞추는 것을 기본 제작 방식으로 삼지 않는다.

새로운 구도나 복잡한 상호작용 때문에 결과가 불확실하면 가장 중요한 장면 하나로 먼저 확인한다. 이미 채택된 구도와 표현을 재사용할 수 있으면 시험용 생성 없이 완성본을 만든다. 고정된 대량 후보 생성이나 무조건적인 컷별 생성은 하지 않는다.

수정할 때는 구도·동작의 문제, 캐릭터 불일치, 글자 오류를 구분한다. 구도가 잘못됐으면 콘티로 돌아가고, 일부만 잘못됐으면 채택한 결과를 편집한다. 유지할 부분과 바꿀 부분을 함께 적는다. 같은 문제가 반복되면 같은 요청으로 다시 뽑지 말고 참조 이미지·장면 복잡도·생성 단위를 재검토한다. 재생성 횟수만으로 원고 오류라고 판단하지 않는다. 후드·의상·색 오류는 참조와 편집 범위를, 반응의 원인이나 전환 오류는 콘티를 먼저 확인한다. 전체 구도가 틀렸다면 컷을 다시 설계할 수 있다.

썸네일의 문구 사용은 [콘티 기준](storyboard.md)의 최소화 원칙을 따른다. 삽화·만화에는 역할에 필요한 짧은 문구를 포함할 수 있다. 긴 한국어 대사나 정확한 UI 문구가 핵심이면 별도 조판을 고려한다. 후처리가 실제로 가능한지 확인하고, 텍스트 수정 때문에 성공한 인물과 구도를 통째로 다시 생성하지 않는다.

## 결과 확인

완성본을 실제로 열어 다음 세 관점으로 확인한다. 캐릭터가 닮았다는 이유만으로 장면이 성공했다고 판단하지 않는다.

- **외형과 연속성:** 현재 기준의 얼굴·후드·의상·소품이 유지되고 컷 사이의 위치와 상태가 이어지는지 본다.
- **용도와 전달:** 썸네일은 제목과 함께 눈길을 끄는지, 글과 맞는 기대를 만드는지 본다. 결론을 설명하지 못한다는 이유로 탈락시키지 않는다. 삽화와 만화는 의도한 비교나 사건, 전체 순서와 넘김 단위의 흐름을 확인한다. 행동이 핵심이면 요청문의 의도와 실제 동작을 구분하고 반대 행동으로 읽히는지 본다.
- **표시 크기:** 작은 썸네일의 전달력, 모바일의 행동·표정·글자, 밝은·어두운 바탕에서의 분리감을 해당 용도에 맞게 본다. 원본 크기에서만 보이는 디테일은 성공 근거로 삼지 않는다.

전달이 약하면 효과나 설명을 더하기 전에 용도에 맞는 장면인지 다시 본다. 실제 독자에게 확인하지 않은 해석은 제작자의 판단으로 기록하고, 브라우저에서 확인하지 않은 배치나 조작을 검증했다고 쓰지 않는다.

선택한 결과·수정 범위·남은 문제를 장면 기록에 남긴다. 제작 중 생긴 우연한 외형 변화는 새 캐릭터 기준이 아니다. 원본 파일을 보존하고 배포 형식·크기는 사이트 지침을 따른다.

## 배포본 마감

사이트 적용 요청이면 PNG 등 편집 원본을 보존하고 배포본을 따로 인코딩한다. 사이트가 본문 이미지를 재압축하지 않는다는 것은 제작자가 압축을 검토해야 한다는 뜻이다. 용량이 큰 배포본은 원본에서 압축 후보를 만들어 비교한다. 장별·전체 용량을 기록하고, 가장 작은 대사와 가는 선을 원본 배율 및 실제 모바일 크기에서 비교한다. 특정 품질이나 장당 용량에 도달했다는 이유만으로 합격시키지 않는다. 작은 글자가 손상되면 품질을 올리거나 무손실 형식을 쓴다.

대체 텍스트는 최종 그림의 행동과 이해에 필요한 문구에 맞춘다. 제작용 미리보기와 실제 사이트 플레이어를 구분하고, 적용 후 모바일·데스크톱과 밝은·어두운 화면에서 잘림·넘침·글자·넘김·확대를 확인한다. 실행하지 못한 항목은 미확인으로 남긴다. 승인 범위가 로컬 반영까지라면 커밋·push·공개 배포로 확대하지 않는다. 구체적인 표시·파일 규칙은 사이트의 AUTHORING.md와 DESIGN.md를 따른다.
